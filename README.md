# Sun of Prosperity — Open House

งานออกแบบ Open House Theme พร้อม Visitor Flow, Staff Allocation และ Scenario Planning

## Concept
- Theme: Sun of Prosperity
- 10 Houses: Sun, Star, Empress, Wheel, Moon, Strength, World, Magician, Lovers, Hierophant
- 20 staff / 2 คนต่อ House
- Floors 12 & 14
- Elevator flow
- Rain scenario
- No-show scenario
- Gold / Orange / Yellow
- Flower / Butterfly / Tarot theme

## Analysis Value
Requirement, Process, Resource Planning, Visitor Flow และ Scenario Planning.
